This was a beginner assignment that has only basic bits and pieces of HTML and Javascript code.

### Basic_HTML_and_CSS
These are a group of small HTML files linked to CSS files to illustrate CSS styling and linking CSS files to 
HTML files in practice.

### The-Pet-Shop-Website
This webpage is about a pet shop demonstrating the use of a navbar and linking pictures and videos as well as other CSS styling effects.

### Simple-Recipes
This webpage includes a navbar and demonstrates the use of hover, rollover, and dropdown effects applied by CSS.

### Creating-CSS-Effects
This webpage includes a navbar and demonstrates hover, zoom, and overlay effect applied using CSS styling.

### One-Page Website
This webpage started off only in HTML and was later updated with CSS styling using elements learned from previous projects.

### Academy Cinemas
This webpage demonstrates building a project for multiple types of screens by adding another CSS file styled for mobile devices as well as for pc. This webpage also demonstrates the use of bootstrap cdn.
